DFT Paper Reproduction - Hydrogen on Slab Model

DFT Reproduction Project

Result

Successfully reproduced the slab construction and hydrogen adsorption setup using a SPARC-based DFT workflow, and documented the process in the project presentation.

Paper reference: 1-s2.0-S0021951723005122-main.pdf

Contents

This project focuses on density functional theory (DFT) replication of the paper's early-stage setup: surface slab preparation, adsorption-site placement, and static energy configuration for hydrogen adsorption.
